# 0012 aa4c.com 只托管静态页面

状态：已接受（2026-10-29）

aa4c.com 是宣传网站：首页、使用场景、下载、文档。邀请链接 `https://aa4c.com/i/#…` 与分享链接 `https://aa4c.com/s/#…`
也落在这个域名下——微信等应用里 `aa4c://` 这类自定义协议链接点不开，https 链接可以。

决定：aa4c.com **只托管静态页面，不运行任何服务、不接触任何用户数据**。链接的载荷放在 `#` 之后，浏览器根本不会把这部分发给服务器；
落地页纯静态，装了 AA4C 就交给 App 打开，没装就教人安装。`/s/` 不代理或保存远程文件；远程接收方安装后再传。
网站不做统计跟踪，不放第三方脚本。允许少量随站点自托管的 JavaScript 尝试唤起 App，但无 JavaScript 时必须仍能看到安装指引。
