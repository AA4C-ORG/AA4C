# 0004 只用 QUIC

状态：已接受（2026-10-29）

第一代同时维护 TCP+TLS（局域网）与 QUIC（跨网）两条平行路径，同一类 bug 要修两遍；还曾因为「写完最后一条消息就丢弃连接」在 QUIC 上
丢掉 `TaskDone`，而 TCP 因内核缓冲宽容没暴露。

决定：设备之间**只用 QUIC**（quinn），局域网也一样。好处：一条代码路径；多个文件天然多流并行；自带保活与连接迁移（换网不断）；
基于 UDP，与打洞同一套机制。

后果：封锁 UDP 的网络（部分公司、酒店）无法直连，只能经中转站；中转站日后可能需要增加 TCP 回退通道，届时另写 ADR。
扫码收发页走 HTTP，不受此限制（它面向浏览器，不是设备之间的协议）。
