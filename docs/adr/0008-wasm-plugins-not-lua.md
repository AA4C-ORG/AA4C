# 0008 插件用 wasmi，不用 Lua

状态：已接受（2026-10-29）。设计见 [book/src/plugins.md](../../book/src/plugins.md)。

插件运行的是别人写的代码，第一要求是**沙箱**：拿不到文件系统和网络，死循环会被终止，内存吃不爆，任何错误都不能让宿主崩溃。

决定：插件是 WebAssembly 模块，跑在 **wasmi**（纯 Rust 解释器）里：零宿主导入，fuel 指令预算 + 墙钟期限，内存上限，每次调用新实例。
插件只返回**意图**（如「把本次收到的文件移到某目录」），由引擎在受限的插件调用上下文里检查能力后执行。
v1 不提供“调用任意命令”的通用意图，避免插件间接取得文件读取与网络能力。参照 storytold/photocraft 的同类做法，
同时把它真实遇到过的畸形模块崩溃样本纳入回归测试。

不用 Lua 的理由：mlua 绑定 C 版 Lua，破坏纯 Rust 并引入 FFI；纯 Rust 的 Lua 实现都不成熟；Lua 标准库要逐个阉割才算沙箱，也没有内建的
指令预算；还会把插件作者锁死在一种语言里。Wasm 任何能编译到它的语言都能写（Rust、Zig、TinyGo、AssemblyScript、C）。

不用 wasmtime：JIT 编译器依赖沉重，且在 iOS 上不可用。
