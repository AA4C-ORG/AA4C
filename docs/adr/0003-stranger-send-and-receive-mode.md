# 0003 附近的人一次性发送与接收模式

状态：已接受（2026-10-29）

第一代规定「配对后才能传输」，附近的陌生设备一律拒收。朋友聚会互发几张照片，也得先走一遍 PIN 配对，这是最常见场景里最重的一步。

决定：**同一网络里的人不需要任何关系就能给我发东西，但每次都要我点「接收」**。接收模式三档：**仅联系人**（默认）、
**所有人**（只能临时打开，最长 10 分钟后自动回到仅联系人）、**关闭**。建立长期关系（加入我的设备、添加联系人）是另一件事，
不再是发送的前提。

防滥用：一次性发送仍然全程加密；收件请求限速（每个来源、全局各有上限），被拒绝的来源进入冷却期；
「所有人」模式下的请求只显示名字和核对码，不自动预览内容。

考虑过的方案：默认「所有人」（像 LocalSend）——最方便，但公共 WiFi 下会被陌生人刷屏；维持必须配对——最严，但核心场景一直很重。
