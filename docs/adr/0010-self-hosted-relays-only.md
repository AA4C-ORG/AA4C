# 0010 只用自建中转站，含社交中转

状态：已接受（2026-10-29）。设计见 [book/src/network/ladder.md](../../book/src/network/ladder.md)。

两台设备都在运营商级 NAT 后、又是对称 NAT 时，直连、IPv6、端口映射、打洞全部失败，只能经中转站转发。
项目可以在 aa4c.com 提供公共中转站，让「远程发送」开箱即用。

决定：**不运行任何官方或公共中转站**。「不依赖第三方服务商」也包括不依赖我们自己：没有要维护的服务器，没有带宽账单，
没有一个能被要求交出数据或被关停的中心。代价是没有常开设备的人，远程发送有时会失败。在原则之内压低这个代价：

1. 连接阶梯先把直连做足（IPv6 → 公网 IPv4 → 端口映射 → 打洞）；
2. 任何常开设备一键成为中转站，地址随设备证书自动分发给我的其他设备；
3. **社交中转**：中转站可选择也为主人的联系人或某个空间的成员服务（默认关闭），一个家庭有一台常开设备，全家及其联系人就都有了兜底；
4. 连不上时说清卡在哪一档、为什么、可以怎么办，绝不静默失败。

中转站只转发端到端加密的密文，不保存任何内容。M4 之后用真机统计各档成功率，用数据判断这个代价有多大；若代价过大，再写新 ADR 重议。

考虑过的方案：aa4c.com 提供可选公共中转站（默认关或默认开）。
