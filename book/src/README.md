# 介绍

AA4C（AA连接，AA for Connection）是一个开源软件，让**人与人之间、设备与设备之间直接传文件**：
不注册账号，不经网盘，不依赖官方服务器；优先直连，必要时经用户选择的自建中转站转发端到端密文。
「把文件 AA 给我」是它的核心；在同一套身份与连接之上，它也让我自己的几台设备彼此连得上，可以 SSH 或远程桌面过去
（[远程访问](network/remote-access.md)）。

这本书是 AA4C 的设计文档，写给三类读者：

- **想了解 AA4C 要做成什么样的人**：从[产品](product/users.md)几章读起。
- **参与设计讨论的人**：重点看[身份与信任](identity/model.md)、[连接阶梯](network/ladder.md)和[待细化的问题](open-questions.md)。
- **写代码的人和 AI agent**：先读仓库根目录的 `AGENTS.md` 与 `GLOSSARY.md`，再看[架构](architecture/overview.md)和[工程规范](engineering.md)。

## 设计原则

- **用户的数据属于用户**：没有中心存储；中转站只转发端到端密文，不保存文件内容。
- **不依赖第三方服务商**：没有账号服务器，没有官方中转站；aa4c.com 只有静态页面。
- **默认安全**：AA4C 设备之间的传输全程端到端加密；信任关系必须由人亲手建立；默认只接收联系人发来的东西。
- **说人话**：界面里不出现 NAT、TLS、mDNS 这类词；出了问题告诉用户发生了什么、可以怎么办。
