# 扫码收发页

让**没装 AA4C 的人**也能收发文件。人与人之间，只有一方装了 App 是常态；这一页决定 AA4C 能不能在朋友之间自然传开。
它是[近场交付](../network/proximity.md)的免安装路径，不是远程网页下载服务。

## 用户看到什么

**发给对方**：我选好文件 →「扫码收发」→ 屏幕出现二维码 → 对方用手机相机扫码 → 浏览器打开一个页面，列出文件，点一下下载。

**让对方传给我**：我点「让别人传给我」→ 出现二维码 → 对方扫码 → 页面上有「选择文件」和「上传」按钮 → 文件到我的「收到的」。

## 怎么实现

- 引擎在可互访的本地 IP 地址上临时开一个**极小的 HTTP 服务**，随机端口，路径带 256 位随机口令：
  `http://192.168.1.20:52341/w/<口令>`。二维码就是这个地址。
- 本地 IP 可以来自共同的局域网，也可以由 Wi-Fi Direct、Wi-Fi Aware 或临时热点建立。建立链路是平台适配器的责任；
  页面、口令、上传下载与限额仍只有一套实现。接收方需要手动加入临时网络时，界面先给出系统步骤，再显示收件二维码。
- 页面是**纯 HTML，不用 JavaScript**（[ADR 0001](../../../docs/adr/0001-rust-engine-native-mobile-shells.md)）：
  下载是普通链接；上传是 `multipart/form-data` 表单。手机浏览器（iOS Safari、Android Chrome、微信内置浏览器）都支持。
- 会话在 10 分钟后、或我点「结束」、或文件全部被下载/上传完成后关闭；关闭后地址立即失效。
- 上传：限制单文件与总大小（可在界面调整），文件名净化后落在「收到的」，每个上传都要我在 App 里点「接收」才算数
  （防止有人在同一网络里乱传东西）。

## 局限（如实说明）

- **只在发送设备可达的本地 IP 链路里有效**。跨网络可用[一次性发送链接](share-links.md)，但接收方必须安装 AA4C；
  不提供“远程浏览器直接下载”。
- **局域网上是明文 HTTP**：浏览器对局域网地址无法使用受信任的 HTTPS 证书（自签证书会弹出吓人的警告，普通人看不懂）。
  口令保证别人猜不到地址，但同一本地链路上有能力抓包的人可能截获内容。界面上对此要有一句话提示：「同一网络里的其他人有可能看到，
  私密文件请让对方装 AA4C 后再发」。⚠ 是否有更好的办法，见[待细化的问题](../open-questions.md)。
- 页面不能自动跳转打开 App；它只负责收发这一次，底部有一行「下次可以装 AA4C，直接发」及下载链接（指向 aa4c.com）。
