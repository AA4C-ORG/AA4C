# aa4c.com 网站

aa4c.com 是 AA4C 的**宣传网站**（[ADR 0012](../../../docs/adr/0012-aa4c-com-static-only.md)：只托管静态页面）。

## 页面

| 路径 | 内容 |
|---|---|
| `/` | 一句话说清 AA4C 是什么；三四个场景（身边的人、手机和电脑、远方的家人、全家相册）；下载按钮 |
| `/download` | 各平台安装包、应用商店链接、Docker 与 `aa4c` 安装命令、校验和 |
| `/docs` | 用户手册（中文优先，附英文）；本设计书的发布版可放在 `/docs/design` |
| `/i/#…` | **邀请链接落地页**：装了 AA4C 由 App 接管（App Links / Universal Links / 桌面自定义协议），没装则引导下载 |
| `/s/#…` | **一次性发送链接落地页**：装了 AA4C 交给 App；未安装显示下载指引。不代理或在浏览器里远程传文件 |
| `/privacy` | 隐私说明：网站不收集任何数据；App 不上报任何数据 |
| `/security` | 漏洞报告方式（dev@aa4c.com）|

`#` 之后的载荷浏览器不会发给服务器，所以即使网站托管方的日志也看不到任何人的身份或分享内容。

## 约束

- 不运行后端服务、不放统计跟踪、不引第三方脚本与字体（字体随站点自托管）。
- `/s/` 不让静态网站看起来像网盘：必须写明发送设备要在线、安装后重新打开链接、网站没有保存文件。
- 落地页可以有极少量 JavaScript 用于「尝试唤起 App、失败则显示下载」——这是网站，不是 AA4C 产品本身，不受「产品不用 JS」的约束；
  但必须在无 JS 时也能看到下载指引（已由 ADR 0012 决定）。
- 微信等应用的内置浏览器通常不会把 https 链接交给 App。`/i/` 与 `/s/` 落地页要写明两条出路：「在系统浏览器打开」，
  或「复制链接 → 打开 AA4C 粘贴」。
- 托管：GitHub Pages（AA4C-ORG 账号下的独立仓库）或其他静态托管，M8 定。
