# 核心功能与范围

功能按「装上它的理由 → 留下来的理由 → 进阶」分三层。括号里是对应的[用户场景](users.md)编号。

## P0：装上它的理由

### 附近互传（场景 1、2）

- 打开 AA4C，看到同一本地 IP 链路里的人和设备：联系人显示名字，附近的人显示名字和头像色块。
- 选中就发：文件、文件夹、**一段文字、一个链接**。文字和链接对方收到后一键复制或打开。
- **附近的人不需要任何关系也能发**，但对方必须点「接收」。接收模式：**仅联系人**（默认）、
  **所有人**（临时打开，最长 10 分钟）、**关闭**（[ADR 0003](../../../docs/adr/0003-stranger-send-and-receive-mode.md)）。
- 发给自己的设备不需要确认；发给联系人可以由对方设为「免确认」。

### 近场交付（场景 1）

- 人在现场时，接收方**安装可选、路径可选**：用 AA4C 加密直连、扫码直接收，或使用当前系统确实支持的文件交付能力。
- 同一局域网、Wi-Fi Direct、Wi-Fi Aware 与临时热点统一视为「本地 IP 链路」：双方已安装时复用 AA4C 传输，
  接收方没安装时复用扫码收发页，不为每种无线方式重写文件协议。
- 系统直传就是调起系统分享面板（AirDrop、Quick Share、蓝牙发送等），按运行时能力显示；平台没有就不出现，不能承诺成全平台共同能力
  （[近场交付](../network/proximity.md)）。

### 扫码收发（场景 1）

- 对方没装 AA4C：我选好文件，点「扫码收发」，屏幕上出一个二维码；对方用手机相机一扫，在浏览器里直接下载。
- 反过来：我点「让别人传给我」，对方扫码后在浏览器里选文件上传给我。
- 页面由我的设备临时提供，只在可互访的本地 IP 链路里有效，10 分钟或传完后自动关闭（[扫码收发页](../surfaces/web-drop.md)）。

### 我的设备（场景 2、6）

- 第一次打开时给自己起个名字，AA4C 生成你的身份（个人密钥），不需要注册。
- 新设备加入「我」：新设备上选「我已经在用 AA4C」，用已有的设备扫它屏幕上的码（或两边比对核对码）。
- 加入后，**我所有的设备和我的联系人都自动认得它**，不需要逐台确认（[身份模型](../identity/model.md)）。
- 我的设备之间：互传零确认；能看到其他设备上共享出来的文件并按需取回；能远程管理常开设备。

## P1：留下来的理由

### 联系人与远程发送（场景 3）

- 当面加：互相扫码，比对核对码。
- 远程加：发一个**邀请链接**给对方（微信、邮件都行），对方点开即加；可以电话里读一遍核对码确认。
- 加一次就认得他所有设备；之后不在一个网络也会经[连接阶梯](../network/ladder.md)尝试直连或使用双方可用的自建中转站。
- 不想加联系人：生成**一次性发送链接**发过去；对方安装 AA4C 后可跨网络接收，不建立联系人关系；可设有效期，随时撤销。
  远程接收必须安装，详见[一次性发送链接](../surfaces/share-links.md)与
  [ADR 0016](../../../docs/adr/0016-no-remote-browser-share-in-v1.md)。
- 连不上时，告诉用户卡在哪一步、可以怎么办，不静默失败。

### 共享空间（场景 4、5）

- 建一个空间（「我们家」「项目组」），邀请联系人成为成员，分配角色：**所有者**、**可编辑**、**只读**。
- 空间里放共享文件夹，在成员的设备之间同步。每个成员自己决定哪台设备存完整副本、哪台只按需取。
- 典型用法：「全家相册」共享文件夹——每个家人的手机把相机目录上传进去，家里的常开设备存全部，所有人都能浏览。
- 可以移除成员；移除后不再同步给他（他已经拿到的副本无法收回，界面上如实说明）。

### 常开设备（场景 4、6）

- 家里的电脑、NAS、小主机可以无界面运行 AA4C（`aa4c` 程序或 Docker 镜像）。
- 在手机或电脑上把它当成「我的设备」远程管理：看状态、加共享文件夹、开关中转站。不用 SSH，不用网页后台。
- 一键成为**中转站**，让我的设备、以及（可选）我的联系人和空间成员在连不上时有兜底（[ADR 0010](../../../docs/adr/0010-self-hosted-relays-only.md)）。

## P2：进阶

- **命令行与 MCP**：`aa4c` 程序驱动全部功能；AI agent 通过 MCP 使用（[MCP 与 AI agent](../surfaces/agents.md)）。
- **插件**：WebAssembly 沙箱插件，处理「收到文件之后怎么办」这类自动化；第一个示例是归档规则（[插件](../plugins.md)）。

## 不做

下载器（HTTP / BT）、AI 与知识库、聊天、云盘、账号体系、社区与公开分发（[ADR 0009](../../../docs/adr/0009-no-downloader-no-ai.md)）。

## 范围冻结

第二代 v1.0 的范围就是本页 P0 + P1。P2 与任何新功能要进入 v1.0，需要先修改本页并说明理由。
